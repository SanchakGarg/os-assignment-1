Who is who

Customers
One party per order. Party size = seats needed (SPACE_REQ). Shirt colour = the order's colour, used everywhere.
Sign "3s 2t"
The party needs 3 seats side by side and 2 tables side by side.
Street
The memory queue (FIFO). Only the head of the line is tried; if it doesn't fit, everyone behind it waits.
Seats 0–5
The SPACE pool. A party sits on adjacent seats. Yellow dashed boxes = free gaps, green box = the gap the allocator chose.
Tables T0–T2
The TABLE pool. A table in the order's colour belongs to it. 0 tables = takeaway (a paper bag).
Ready queue
Tickets in the order the scheduler will pick them. The highlighted line on each ticket is what the scheduler looks at.
Chefs
The 2 CPUs. The bubble shows the order being cooked and its progress. A chef walks to a machine while the order uses it.
Machines
Shared resources, one user at a time. Light: green = free, red = in use, grey = not in this scenario. The badge shows the holder.
Red tags above a machine
Orders blocked waiting for that machine, first in line on the left. They keep their seats and anything they hold.
Wall clock
The hand sweeps once per clock cycle.

ALL FOUR CONDITIONS HOLD

    
    
      
  • Mutual exclusion: each machine serves one order at a time.
    • 
      
  • Hold and wait: each order keeps one machine while it waits for another.
    • 
      
  • No preemption: a machine is never taken away from its holder.
    • 
      
  • Circular wait: the orders wait for each other in a circle (above).
    • 
    

    
The server found the cycle in the wait-for graph, stopped every worker thread and ended the run. With prevention ON, an order that asks for a lower-ranked machine while holding a higher one gives it back first (ROLLBACK), so the circle can never close.
